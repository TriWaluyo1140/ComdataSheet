Siapkan akses admin

Sekali saja per perangkat. Token GitHub disimpan terenkripsi di browser ini dan hanya bisa dibuka dengan PIN Anda.

Cara membuat token
  1. Buka GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Token name: Admin ComdataSheet. Expiration: pilih (misal 1 tahun).
  3. Repository access: Only select repositories → pilih ComdataSheet.
  4. Permissions → Repository: Contents: Read and write dan Actions: Read and write.
  5. Klik Generate token, salin, lalu tempel di atas.
